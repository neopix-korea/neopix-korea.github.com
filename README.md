# AI BOOTCAMP 온라인 강의실

MAKE · CONNECT · BUILD 소개와 MAKE 1–15강 썸네일 목록을 제공하는 반응형 정적 웹사이트입니다.

## 열기

`index.html`을 브라우저에서 열면 됩니다. 별도의 빌드나 패키지 설치는 필요하지 않습니다. 일반 정적 웹호스팅 또는 GitHub Pages에도 올릴 수 있습니다.

- 첫 화면: `/`
- MAKE 목록: `make/index.html`
- 강의 검색 및 브라우저 뒤로 가기 지원

## 강의 콘텐츠

실제 강의 제목·소개·동영상은 아직 제공되지 않아 1–15강을 준비 중 상태로 표시합니다. `app.js`의 `lessons`에서 강의 정보를 수정할 수 있습니다. MAKE 강의실에는 Firebase 기반 과제 출제·작품 제출·실시간 검토 화면이 있습니다. 연결 정보와 운영 규칙은 firebase/SETUP.md를 참고하세요. CONNECT와 BUILD는 소개만 표시합니다.

원본 InDesign/PDF 자료는 로컬에 보존하며 Git에는 포함하지 않습니다. `backups/`의 ZIP은 웹 소스 백업입니다.

## 개별 MAKE 강의실

make/01/부터 make/15/까지 각 폴더의 index.html이 독립적인 강의 주소를 제공합니다. make/thumbnails/01.svg부터 15.svg까지 각 강의의 레드 모티브 썸네일이며, 목록과 개별 강의실에서 같은 파일을 사용합니다. 개별 강의실에는 이전·다음 강의 이동, 영상 및 과제 준비 중 안내가 있습니다.


## 실습 과제

MAKE 목록 상단 QR 아래에서 학생 아이디와 비밀번호를 등록하고 로그인합니다. 브라우저가 입장 정보를 기억하며, 자리 이동 시 좌석 변경으로 새 좌석을 지정할 수 있습니다. 학생은 로그인한 본인 제출물만 조회할 수 있고, 교수만 전체 제출물을 조회합니다. 교수는 기존 Google 계정으로 로그인해 과제를 공개·마감하고 홈페이지·Suno 링크·이미지 제출물을 실시간 검토합니다. 스크린 화면은 make/index.html?screen=1에서 제공합니다.
